# MultiBT

[English](README.md) · **中文**

> **Windows 一直缺的那个「多输出设备 + 自动同步」按钮。**
> 不做音频工作站，不做 Voicemeeter 克隆，不做内核驱动。

把一份系统声音同时送到多个输出设备——蓝牙音箱、USB 声卡、HDMI 投影——每台设备有
**独立的音量与延迟**，并且 MultiBT 会在**播放过程中持续纠正它们的时钟漂移**，
不会几分钟后就慢慢错开。

配置一次，重启后自己恢复。**日常不需要打开主窗口。**

```text
                Windows 音频
                     │
                     ▼
              MultiBT 引擎
        ┌────────────┼────────────┐
        ▼            ▼            ▼
     蓝牙          USB          HDMI
   + 120 ms      + 40 ms       + 0 ms
```

## 为什么需要它

Windows 本来就能把一路声音送到多个设备。缺的是大家真正需要的那部分：

* 每台设备的**延迟都不一样**，所以它们听起来不像一套系统；
* **蓝牙设备比有线慢 150–400 ms**，这不是「在系统里多勾两个输出」能解决的；
* 设备之间会**持续漂移**，一开始同步的组合过几分钟就糊了；
* 而**默认输出设备根本无法被延迟或调音量**——Windows 直接放给它，不经过任何程序。

MultiBT 就是来解决这四件事的，然后在之后尽量不打扰你。

## 它做什么

* **一路声音，多个音箱** —— 任意数量的输出端点同时打开。
* **每设备延迟** —— 0–2000 ms，走真正的延迟线，不是拿缓冲区凑数。
* **每设备音量** —— 直接驱动设备**真实的 Windows 音量**，所以滑杆 100% 就是设备的 100%，
  而且界面显示的就是设备的实际值。
* **持续漂移纠正** —— 5 Hz 控制环测量每台设备的缓冲，用可调速重采样把它拉回来，
  所以是几小时保持对齐，而不是几分钟。
* **设置不用手动保存** —— 改动即持久化，并且支持 **Ctrl+Z / Ctrl+Y** 在改动之间前后穿梭。
* **扛得住设备插拔** —— 热插拔自动检测；蓝牙音箱重新连上后会自动重新接管。
* **场景配置** —— 一组命名的设备与音量组合，方便在「客厅」「桌面」之间切换。
* **数字诚实** —— 界面给出系统端到端延迟，并在超过口型同步明显失效的阈值时报警。

## 快速开始

1. 下载 `MultiBT-Preview-win-x64.zip`，解压，运行 `MultiBT.App.exe`。
2. 在列表里勾选你要的输出设备。
3. 看「**音频输入**」——`自动` 跟随你的 Windows 默认输出，大多数情况下这就是对的。
4. 点「**▶ 开始同步**」。

### 需要虚拟声卡吗？

**不需要。** MultiBT 捕获的是你 Windows 默认输出正在播放的内容，所以开箱即用，什么都不用装。

装一个虚拟声卡（VB-CABLE、VoiceMeeter、Virtual Audio Cable 等）会让它**更好**，但只在一点上：
Windows 会把声音渲染进一个没人听的设备，于是**每一台**音箱都能成为 MultiBT 的输出——
**包括原来那个默认设备**。没有虚拟声卡时，那台设备会自己原生播放，MultiBT 也就无法延迟它、无法调它的音量。

程序里的「**获取虚拟声卡**」按钮会列出几个选择并打开厂商官网。
**MultiBT 只做推荐，不打包、不下载任何东西。** 原因见 [docs/DECISIONS.md](docs/DECISIONS.md)。

## 已知限制

老实写出来——只列优点的 README 没有用：

* **对齐到蓝牙设备要付出延迟。** 所有设备都会被延到最慢的那台，这可能让系统超过约 125 ms，
  于是视频看起来对不上口型。看视频请用 **WiredOnly** 同步模式。
* **声学延迟没有测量。** 麦克风校准还没有端到端打通，所以自动对齐基于**按传输类型给出的估算**
  （蓝牙 200 ms、HDMI 20 ms、有线 10 ms）。估算不准的残差由手动微调吸收。
* **这是预览版。** 音频通路已经在真机上做过端到端验证——真实音频同时到达多台设备，**声像和延迟都是实测的
  下游数据**而不是推断——但还没有做声学测量，也没有在足够多的硬件上试过。
* 音箱自身的灵敏度差异无法自动修正；能对齐的只有 Windows 音量。
